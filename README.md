Smart Energy Auditor ⚡

Smart Energy Auditor is a simple application designed to help users understand their electricity consumption, estimate electricity costs, and explore solar energy solutions.

Features

- Energy Calculator: Calculate electricity consumption based on device power and operating hours.
- Cost Estimator: Estimate electricity bills based on energy usage and electricity price.
- Solar Estimator: Estimate the solar panel capacity required to meet daily energy needs.
- Solar Panel Calculator: Estimate the number of solar panels needed.

Technologies Used

- Python
- Streamlit
- Git and GitHub

How to Run

Install the required libraries:

pip install -r requirements.txt

Run the application:

streamlit run app.py

Purpose

This project is an educational tool for understanding energy consumption and exploring renewable energy solutions. Its calculations are estimates, not professional engineering designs.
